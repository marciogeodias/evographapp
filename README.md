Projeto vinculado a disciplina de projeto integrador II do curso de ciência de dados da UNIVESP. O aplicativo em questão apresenta um diagnóstico, a partir de provas no Google formulário que geram planilhas CSVs, sobre a evolução dos alunos nas habilidades e competências da BNCC, além de verificar a quantidade de faltas de cada aluno denunciando os alunos com muitas faltas como risco de reprovação.
